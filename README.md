# 🔥 Inferno Grade Tracker

> Потому что одна **двойка** должна приносить хотя бы немного удовольствия.

**Inferno Grade Tracker** — desktop-приложение на Python, которое автоматически отслеживает появление плохих оценок на экране и превращает их в небольшую систему наказаний, наград, комбо и достижений.

Иными словами: приложение замечает, когда жизнь решила тебя немного поиметь, и фиксирует это событие.  

---

## 🧠 Как это работает

Приложение следит за выбранной областью экрана и ищет в ней характерный цвет оценки.

```text
┌─────────────────┐
│     Экран       │
│                 │
│      [ 2 ]      │ ← detector
│                 │
└────────┬────────┘
         │
         ▼
    Color detection
         │
         ▼
    Grade detected
         │
    ┌────┴─────┐
    ▼          ▼
 Statistics   Reaction
    │          │
    ▼          ▼
  Combo      Overlay
  Gold       Sound
  Rank       Meme
  XP         Animation
```

После обнаружения события приложение обновляет статистику и запускает соответствующую реакцию.

### Основные модули

**`main.py`**  
Точка входа и координация основных компонентов приложения.

**`modules/detector.py`**  
Захватывает выбранную область экрана и определяет появление нужного цвета с помощью NumPy и HSV.

**`modules/calibrator.py`**  
Помогает настроить область и параметры детектирования.

**`modules/stats_manager.py`**  
Отвечает за локальную статистику, combo, progression и связанные игровые механики.

**`modules/cloud_profile.py`**  
Работа с профилем пользователя и Supabase.

**`modules/login_sync.py`**  
Синхронизация локального состояния с cloud profile и проверка подозрительных расхождений.

**`modules/overlay.py`**  
Отображение визуальных реакций поверх других окон.

**`modules/meme_manager.py` / `sound_manager.py`**  
Мемы и звуковые реакции на события.

## 🔥 Detector

Основная техническая часть проекта — автоматическое распознавание оценки.

Приложение:

1. Получает screenshot выбранной области.
2. Преобразует изображение в HSV.
3. Создаёт маску подходящих по цвету пикселей.
4. Вычисляет их процент от общей площади.
5. Сравнивает результат с заданным threshold.
6. При обнаружении события отправляет сигнал приложению.

Чтобы одна и та же оценка не засчитывалась несколько раз подряд, используется cooldown и отслеживание перехода состояния.

```text
no grade
    │
    ▼
color detected
    │
    ▼
 threshold exceeded
    │
    ▼
  EVENT
    │
    ▼
 cooldown
```

## ☁️ Cloud

Supabase используется для хранения данных профиля и синхронизации прогресса.

В профиле могут храниться:

- статистика;
- gold;
- keys;
- rank/title;
- achievements;
- referral data;
- leaderboard information.

Локальные настройки приложения при этом отделены от данных прогресса.

---

## 🛡️ Anti-tamper

Приложение также проверяет подозрительные расхождения между локальным и cloud-состоянием.

Это не претендует на полноценную защиту от читов — desktop-клиент в любом случае нельзя считать полностью доверенной стороной.

Цель системы скорее в том, чтобы обнаруживать очевидные изменения локального прогресса и реагировать на них.

## 🚀 Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Создать локальный конфиг на основе:

```text
config.example.json
```

После этого запустить:

```bash
python main.py
```

> Для работы cloud-функций необходимо настроить соответствующие Supabase credentials.

## 💭 Почему я это сделал

Потому что обычный grade tracker просто записывает оценку.

**Inferno Grade Tracker сначала замечает двойку, потом делает из неё событие, статистику, комбо и маленький эмоциональный кризис.**

И это, как ни странно, оказалось гораздо интереснее.
